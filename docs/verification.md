# Публічна версія 1.0

Дата підготовки: 2 листопада 2026 року. Фінальну версію та відкриття репозиторію погоджено користувачем.

- Підготовлено GitHub Actions workflow `Deploy to GitHub Pages`: Node.js 24, збірка, 8 тестів і публікація лише `site/`.
- Версії офіційних GitHub Actions зафіксовано за повними commit SHA. Публікувати може лише гілка `main`.
- Перед відкриттям перевірено 34 Git-blob історії: відомих форматів секретів, абсолютних користувацьких шляхів, вхідних PDF чи налаштувань чужого хостингу не виявлено. Це перевірка відомих шаблонів, не гарантія виявлення будь-якого секрету.
- Локальні збірка й усі 8 тестів пройшли. YAML перевірено; каталог артефакту — `site/`.
- Поточний результат розгортання: [GitHub Actions](https://github.com/Lisercool/turkiye-economic-security/actions/workflows/pages.yml).
- Адреса публікації: https://lisercool.github.io/turkiye-economic-security/.

Нижче наведені історичні перевірки локальних версій до публікації.

# Перевірка версії 0.2

Дата: 2 листопада 2026 року. Репозиторій приватний; публікацію не ввімкнено.

За запитом користувача спрощено три сторінки: звичайний шрифт і біле тло, компактні заголовки, вилучені декоративні банери та картки, скорочені повтори, методичні шкали розгортаються окремо. Номер телефону оновлено, посилання для дзвінка перевірено без здійснення дзвінка.

- 8 тестів даних і розрахунків пройдено. CSV байтово збігається з версією 0.1, усі 45 спостережень і класифікацій збережені.
- 43 внутрішніх посилань, файлів і якорів існують; повторених ID немає.
- У браузері перевірені фільтри року та рівня: 2025 рік і фільтр «Потребують уваги» дають коректний порожній результат.
- Зведення містить п’ять колонок на широкому екрані. На вузькому — три, а роки й оптимальні інтервали показані під відповідними значеннями.
- Перевірені CSS-ширини 390, 468, 526 і 1280 px. Загального горизонтального переповнення немає; зведена таблиця при 390 px вміщується в 350 px.
- У методиці наявні всі сім шкал; за замовчуванням розгорнута одна. Розгортання іншої шкали працює.
- Торговельний коефіцієнт 2023 року відображається як 0,9450 і залишається небезпечним.

Системний друк/PDF не виконувався. Стилі друку показують усі групи й повну зведену таблицю; обробники друку розгортають усі методичні шкали та відновлюють їхній стан після друку.

# Історична перевірка локальної версії 0.1

Дата: 2 листопада 2026 року. Публікацію не виконано.

## Дані та логіка

8 автоматичних тестів пройдено без помилок: усі 45 спостережень і класифікацій; останні значення з таблиці 15; обчислення з початкових величин до округлення; усі межі семи шкал; відсутність заповнення пропусків; напрям динаміки та одиниці; CSV; три окремі сторінки, 7 графіків і 45 точок.

Команда: `node --test tests/*.test.mjs`. Синтаксис шести JS/MJS-файлів перевірено через `node --check`. Збірка: `node scripts/build.mjs`.

## Сервер і межі перевірки

Головна, аналітика, методика, JavaScript і CSV повертають HTTP 200. Відповіді містять no-store, nosniff та CSP із frame-ancestors none. Шляхи `.git`, `.env`, приватної документації, генератора, package.json та невідомих файлів повертають 404. Сервер слухає лише 127.0.0.1.

PDF через системний діалог фізично не зберігався; стилі друку показують усі 7 груп. Не перевірені всі браузери й допоміжні технології. Зовнішні статистичні сторінки можуть відповідати з затримкою та переглядати дані; повторної повної числової звірки з їхніми поточними значеннями не виконано. Робочий набір відтворює надану теоретичну частину.

GitHub Pages і фінальна публічна адреса перевірятимуться на етапі публікації після погодження користувачем.
