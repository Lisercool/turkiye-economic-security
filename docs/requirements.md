# Відповідність практичному завданню

Основа — наданий файл «Практична частина.pdf», 2 сторінки. Вимоги документа використані як технічне завдання. Після локальної перевірки користувач 2 листопада 2026 року погодив фінальну версію, відкриття репозиторію та публікацію через GitHub Pages.

| Вимога | Реалізація |
| --- | --- |
| Щонайменше дві взаємопов’язані сторінки | Три окремі HTML-сторінки: автор, аналітика, методика |
| Головна сторінка про автора | Задане ім’я Лошак Ю. О.; компактне формулювання освіти; професійні інтереси; контактний номер користувача |
| Навігаційне меню | Спільне меню на кожній сторінці, позначення активної сторінки |
| Обрана країна | Туреччина в усіх даних, заголовках і висновках |
| Показники теоретичної частини | Усі 9 рядів у 7 групах, 45 спостережень |
| Таблиці та графіки | Зведена таблиця, 7 детальних таблиць і 7 SVG-графіків; 2 лінії для показників за статтю |
| Факт проти порогів | Рівні в усіх таблицях, оптимальні інтервали, порогові лінії на графіках, повні шкали в методиці |
| Безпечні та небезпечні тенденції | Показано наближення до оптимуму, зміну оцінок за роками та змістовні висновки. Покращення показника не ототожнюється з безпечним рівнем |
| Загрози та узагальнений висновок | Окремі блоки загроз, пріоритетів і підсумкового висновку на аналітичній сторінці |
| HTML, CSS, JavaScript | Статичні HTML-сторінки та локальні ES-модулі без зовнішніх залежностей |
| Різні пристрої | Адаптивна верстка; великі таблиці й графіки прокручуються локально |
| Автор і рік у підвалі | Лошак Ю. О., 2026, на всіх сторінках |
| Перевірка | Автоматичні перевірки даних, інтервалів, CSV та розмітки; браузерна перевірка |
| GitHub Pages і фінальне посилання | GitHub Pages через Actions: https://lisercool.github.io/turkiye-economic-security/ |

Контактний телефон вказаний користувачем. Професійні інтереси — запропонований текст відповідно до спеціальності, а не незалежно підтверджена біографія.

Публікація виконується з папки `site/` після перевірок у workflow `Deploy to GitHub Pages`. Репозиторій і фінальний сайт публічні за прямою вказівкою користувача.
