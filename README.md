# Економічна безпека країни — Туреччина

Локальна версія 0.2 навчального сайту за наданою практичною та теоретичною частинами. Автор на сайті: **Лошак Ю. О.**

**Статус: приватний репозиторій, без публікації. GitHub Pages не ввімкнено.** Відкриття репозиторію та розгортання виконуються пізніше, після погодження фінальної версії.

## Локальний запуск

Потрібен Node.js 22–24. Сторонніх залежностей немає.

```sh
node scripts/build.mjs
node server.mjs
```

Відкрити **http://127.0.0.1:4174/**. Зупинити сервер — `Ctrl+C`. Інший порт: `PORT=8080 node server.mjs`.

Також доступні `npm run build`, `npm start`, `npm test`, якщо npm є у PATH. `file://` не підходить для браузерних ES-модулів: використовуйте HTTP.

## Сторінки

- `site/index.html` — автор, освіта, професійні інтереси, контакти та короткий опис дослідження.
- `site/analytics.html` — зведення 9 показників; вибір року без заповнення пропусків; фільтри оцінок; 7 графіків, усі 45 спостережень у таблицях; порівняння з оптимальними й іншими інтервалами; загрози, пріоритети та висновок.
- `site/methodology.html` — формули, усі 7 шкал, джерела та обмеження аналізу.
- `site/assets/turkiye-data.csv` — повний набір даних з початковими величинами й оцінками.

Методичні шкали розгортаються окремо. Графіки доступні для навігації клавіатурою; на вузьких екранах прокручуються всередині власного контейнера. Усі дані також подані таблицями. Без JavaScript сім груп показані послідовно. Друк включає всі групи, незалежно від обраного графіка.

## Джерела й відтворюваність

Числа та шкали зафіксовані за наданим PDF «Лошак_Теорія.pdf», а не завантажені заново з актуальної бази. Документ не вказує дату вивантаження та нормативне походження порогів. На сайті це пояснено; шкали не оголошуються офіційними стандартами Туреччини або Світового банку.

Ряди мають різні періоди: 2019–2023, 2020–2024, 2021–2025. Їх не зведено у вигаданий спільний рік чи інтегральний бал. Для похідних показників оцінка виконується до округлення. Торговельний коефіцієнт 2023 року 0,9450387… залишається небезпечним, хоча до двох знаків це 0,95.

Профіль задано користувачем; професійні інтереси сформульовано відповідно до спеціальності. Контактний номер задано користувачем; на сторінці він оформлений як посилання для дзвінка.

## Зміни та перевірки

Профіль і дані: `site/assets/data.js`. Логіка інтервалів: `site/assets/model.js`. Графіки: `site/assets/charts.js`. Шаблони сторінок: `scripts/build.mjs`. Після їх зміни перегенеруйте HTML і CSV:

```sh
node scripts/build.mjs
node --test tests/*.test.mjs
```

Деталі: [відповідність ТЗ](docs/requirements.md), [перевірка даних](docs/data-audit.md), [перевірка реалізації](docs/verification.md).

## Майбутня публікація

Каталог публікації — **тільки `site/`**. Усі внутрішні посилання відносні й підходять для адреси проєкту GitHub Pages. Після фінального погодження можна зробити репозиторій публічним, налаштувати Pages із завантаженням вмісту `site/` через Actions і перевірити фінальну адресу. Автоматичного workflow публікації в цьому репозиторії немає.

Вхідні PDF, знімки перевірки, абсолютні локальні шляхи та налаштування хостингу іншого проєкту до репозиторію не включені. Власний код сайту не має аналітики, cookies, мережевих API чи записів до сховищ браузера. Локальний сервер слухає лише 127.0.0.1 та не видає файли за межами явного списку `site/`. Він призначений для перегляду, а не публічного серверного хостингу.
